# ADR-0074 · unicron 0.16: the Mac icons come from unicron, and Vale's stand-in goes

- **Status:** Accepted
- **Date:** 2026-11-02
- **Builds on:** [ADR-0069](0069-unicron-0-9.md) (unicron 0.9), [ADR-0073](0073-icons-by-code-point-and-the-rail.md) (the code-point stand-in)

ADR-0073 fixed blank icons in the Mac app with a Vale-side `Icon` that draws Material Symbols by code point, and said it belonged in unicron. unicron had already fixed the same bug, differently, in 0.13.1. Vale was on 0.9. This moves Vale from `@unicron/ui` 0.9.0 and `@unicron/tokens` 0.7.0 to 0.16.0 and 0.10.0.

## Decisions

- **The cause, corrected.** WebKit does join the letters into the icon. It centres SVG text by the width of the separate letters before the font joins them, so a centred icon landed far left, outside its box. unicron 0.13.1 ([snds/unicron#49](https://github.com/snds/unicron/pull/49), found in Synapse's Mac app and checked in WebKit and Chromium) anchors the glyph at the left edge; every Material Symbol is exactly 1em wide.
- **Vale's stand-in goes:** the Vite plugin in `apps/web/vite.config.ts`, `src/lib/unicron-icon.tsx`, the code-point map and `scripts/icon-codepoints.py`. The ratchet's look-alike goes back to 0.
- **unicron's `Icon` stays on ligatures.** A code-point map would add about 31 KB (gzipped) to every app on unicron for a bug it already fixed.
- **Take the rest as it is.** No Vale code changes. What 0.10 to 0.16 change on screen:
  - Dialogs fit their content between a min and a max width. Each min is the old fixed width, so none gets narrower.
  - Three text levels: secondary text (`--muted-foreground`) sits a level below primary, and descriptions take the new `--support-foreground`.
  - A pressed state on every Button variant and interactive `Item` row; stronger invalid-field and destructive focus rings.
  - Orientation styles work (tab markers, separator sizes, scroll bars), and icons keep their case inside uppercase labels.
  - New, unused here so far: `closeOnOutsideClick`, sticky dialog and sheet footers, `DropdownMenuContent width`, `SheetContent backdrop` and `size`, `TabsList size="fill"`, text roles (`type-*`), `SheetHeaderActions`.

## Verification

- `tsc -b`, `oxlint`, `vite build` and `pnpm build:demo` are clean.
- **Ratchet:** className overrides flat at 210; look-alikes 1 → 0.
- unicron 0.16's built `Icon` anchors the glyph at `x="0"`.
- **On a Mac:** this change touches `vite.config.ts`, so the PR's Mac workflow builds a dmg; opening it is the WebKit check.

## Consequences

- **Screens shift slightly:** lighter secondary text, pressed states, and dialogs that can grow wider. That's intended upstream.
